One correction on the model choice, since it affects the whole backend design: **Groq doesn't do video or image generation** — it's a fast LLM/audio inference API (Llama, Whisper, etc.), no generative-image or video models on it. For a free/cheap stand-in for the real thing (Sora/Veo/Runway/GPT Image are all paid, no free tier), better options are:

- **Images:** [Pollinations.ai](https://pollinations.ai) (genuinely free, no key, decent quality), or Google's Gemini API image generation (has a free tier), or Hugging Face Inference API (free tier, slower/rate-limited).

Options: Hugging Face Inference API hosting an open model (slow, often queued), or Replicate (not free but cheap pay-per-run, good free trial credit), or just mocking/stubbing video generation behind the same UI/credit-flow (fake job → returns a stock/sample clip) if a real free video model turns out impractical in the time budget.

**How auth works:**

- With a free key ("Seed" tier): faster (~1 req/5s), some perks like no watermark.

**Two different endpoints, don't mix them up:**
